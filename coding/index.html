School Features スクールの特徴

1👑

外国人講師と日本人スタッフによる預かり空間 日本人・外国人講師がいるので英語初心者でも安心。遊びや片付けなどの日常シーンを通じて、自然に英会話が身につきます。

2👑

公用語は英語！長時間の英語環境 英語「で」学ぶカリキュラムをつ通じて、英語の学習のみならず、自信・自制心・コミュニケーション能力・協調生など、将来に役立つソーシャルスキルの習得を目指します。

3👑

実力を形に！４技能英語学習 暗記に頼らず遊びを通じて語彙を習得。単なる英語環境を超え、4技能をバランスよく鍛えながら小学校卒業までの英検3級合格を目指します。

4👑

「使える英語」と「探究心」 アート・音楽・フォニックス・探究活動などをプログラム構成。さまざまな分野に英語で触れ、学問の枠にとらわれない学びの時間を提供します。
